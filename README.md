# 産業医面談 資料

産業医面談で使う資料・入力ページを置いています。

## 生活記録表（Web版）

**URL：https://sangyoui.github.io/mendan/seikatsu/**

- 休職中・復職前・就労中の方に、1週間分の生活リズム（睡眠・日中の活動・気分）を記録していただくページです。
- PC・スマホのブラウザで開くだけで記入できます。アプリのインストールやログインは不要です。
- 記入が終わったら、「③ 送る」の画面から、記録をPDFにして、メール・LINE・その他のアプリ（Teams・Slack・Chatworkなど）で担当者へ送っていただきます。スマホでは、PDFが添付された状態でメールやLINEが開きます。

### 個人情報について

- 入力内容は、記入する方の端末（ブラウザ）の中にだけ保存され、インターネット上には送信されません。
- このリポジトリには、記入用のページ（`seikatsu/index.html`）だけを置いています。**記入済みの記録（画像・Excel）は、このリポジトリに絶対にアップロードしないでください。**（このリポジトリは公開設定です）

### 更新のしかた

1. `seikatsu` フォルダを開く
2. 右上の「Add file」→「Upload files」で、新しい `index.html` をアップロード
3. 「Commit changes」を押す（数分で同じURLに反映されます）
